# COLOR MEISTER

赤・緑・青の3色を調合して、お題の色を再現するブラウザゲームです。

## 🎨 遊び方
1. ランダムに表示されるお題の色を確認します。
2. 赤・緑・青のスライダーを動かして、ビーカーの色を調合します。
3. 「この色で決定！」を押すと、色の近さを0〜100点で採点します。
4. 全5ラウンドで色合わせに挑戦できます。
